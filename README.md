# Weather Dashboard 

A Python application that fetches real-time weather data using the OpenWeatherMap API.

## What it does
- Search current weather for any city
- Displays temperature, humidity, and weather conditions
- Built to understand how APIs work in real projects

## Tech used
- Python
- OpenWeatherMap API
- Requests library

## How to run
1. Clone the repo
2. Install dependencies
3. Add your API key inside "weather.py"
4. Run the app

## What I learned 
- How to connect to a third party API
- Handeling JSON responses in Python.
- Structuring small python project
